# SafeHer – Women's Safety Web Application

SafeHer is a women’s safety web application designed to provide quick access to emergency assistance tools and promote personal safety through technology.

## Features

- Emergency Contact Management – Add, edit, delete, and call emergency contacts.
- SOS Alert – Emergency alert simulation with a countdown timer.
- Safety Tips – Helpful tips for personal safety.
- Location Sharing – Share your location through Google Maps and WhatsApp.
- Voice Commands – Access safety features using voice commands.
- Emergency Message – Copy and share predefined emergency messages.
- Dark Mode – Switch between light and dark themes.
- Feedback System – Submit feedback about the application.
- Favourite Safety Tips – Save your favourite safety tips.

## Technologies Used
